Purpose and scope

This project examines how inferred binary-black-hole properties change when the same gravitational-wave event is analyzed with two released waveform configurations: IMRPhenomXPHM-SpinTaylor and IMRPhenomXPNR. It visualizes configuration sensitivity; it does not determine which waveform is more accurate.

The scientific question remains open. The true source parameters are unknown, posterior intervals are conditional on each released analysis configuration, and the selected events do not represent a population-prevalence estimate. Conclusions are therefore limited to the compared C00 configurations and the study samples.

Study design and statistical status

Development
Seventeen method-development events were used before confirmation and are separate from the events displayed as confirmatory or replication evidence.
Confirmation
Eighteen events were balanced across a 3 × 3 screening-score/SNR design, with two events per cell. The event—not an individual posterior draw—is the unit of inference.
Hypotheses
H1 was the sole primary hypothesis. H2 and H3 formed a Holm-adjusted secondary family; all three prespecified results are reported on the Explore page.
Replication
Nine previously unprocessed reserve events, one per design cell, tested one prospectively locked H3 hypothesis after selection was frozen.
Numerical audit
The confirmatory run records metric definitions, input SHA-256 hashes, fixed seeds, sample audits, and 100,000-permutation settings in a machine-readable manifest.

Exploratory mechanism analyses and post-confirmatory robustness checks are labeled separately from the prespecified tests throughout the visualization.

Author

Thomas McCurley, Sierra Canyon School, created the analysis and interactive site. The project combines reproducible statistical analysis with a public-facing explanation intended for readers with a range of gravitational-wave backgrounds.
