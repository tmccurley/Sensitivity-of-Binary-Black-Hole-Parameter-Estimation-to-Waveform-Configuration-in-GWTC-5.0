Purpose and scope

This project examines how inferred binary-black-hole properties change when the same gravitational-wave event is analyzed with two released waveform configurations: IMRPhenomXPHM-SpinTaylor and IMRPhenomXPNR. It visualizes configuration sensitivity; it does not test which waveform is more accurate.

The study separates 17 method-development events from an 18-event balanced confirmatory sample. A prospectively locked nine-event reserve sample then tests whether the effective-spin-versus-distance ordering repeats. Additional analyses examine robustness, posterior storage diagnostics, and possible joint mass-ratio-spin mechanisms.

The balanced score-by-SNR design broadens coverage but does not estimate catalog-wide prevalence.

Author

Thomas McCurley, Sierra Canyon School, created the analysis and interactive site. The project combines reproducible statistical analysis with a public-facing explanation intended for readers with a range of gravitational-wave backgrounds.
